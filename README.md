## Projetos em destaque

### 📱 Meu Jogo

**Aplicação mobile para organização e gerenciamento de partidas de futebol e futsal.**

Projeto desenvolvido com o objetivo de facilitar a organização de jogadores, equipes e partidas, considerando situações comuns de jogos entre amigos.

**Funcionalidades trabalhadas:**
- Organização de jogadores e equipes.
- Distribuição de times com base nas características dos jogadores.
- Organização de posições em quadra.
- Gerenciamento de partidas e dinâmica de equipes.
- Interface pensada para utilização em dispositivos móveis.

**Tecnologias:** React Native, Expo e TypeScript.
